# Dispersion specification

Exposure averaging period is 1 hour. Receptor list and output ordering are as in network.npz receptor_xy. Covariance factor L units are (ug/m3)^2 in variance space; whiten by triangular solve. Admissible interval for each theta_j is prior mean +/- 3 sigma_theta in log space. Short-term exposure limit is 50 ug/m3.
